## What it does

Auto-advances the boot and main-menu screens into your **last character + world**. The game already defaults those selections; this mod presses the primary Play / Confirm / Enter World buttons for you.

## Why install it

Vanilla makes you click through a pile of screens every launch. This gets you into Ashenfall faster.

## How to use it

1. Install [UE4SS for RSDragonwilds](https://www.nexusmods.com/runescapedragonwilds/mods/4).
2. Extract this mod into `RSDragonwilds\Binaries\Win64\ue4ss\Mods\` (so you have `Mods\QuickLaunch\Scripts\main.lua`).
3. Confirm `mods.txt` has `QuickLaunch : 1` (or leave `enabled.txt` in the mod folder).
4. Launch the game — it should walk itself into the last session.

**Hold Escape** during the front-end to cancel and take over manually. Destructive buttons (Delete, Quit, Create, Join server, etc.) are avoided.
