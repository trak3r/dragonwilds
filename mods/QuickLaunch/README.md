# Teflon Ted's Quick Launch

> **One mod, one job** — no kitchen-sink configs or feature creep.

Auto-advances boot/main menus into your last character + world. **Escape** cancels.

Player-facing Nexus copy, icon, and changelog live in [`nexus/`](nexus/). Pack with `..\..\Pack-Nexus.ps1 -Mod QuickLaunch`.

Requires [UE4SS for RSDragonwilds](https://www.nexusmods.com/runescapedragonwilds/mods/4).
