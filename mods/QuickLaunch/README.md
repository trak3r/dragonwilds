# Teflon Ted's Quick Launch

> **One mod, one job** — no kitchen-sink configs or feature creep.

<a href="https://buymeacoffee.com/teflonted"><img src="https://img.buymeacoffee.com/button-api/?text=Buy%20me%20a%20coffee&slug=teflonted&button_colour=FFDD00&font_colour=000000&font_family=Lato&outline_colour=000000&coffee_colour=ffffff" width="174" alt="Buy me a coffee" /></a>

Auto-advances the boot/main-menu flow into your **last session**. The game already defaults the last character and world in those screens; this mod clicks the primary Play / Confirm / Enter World actions for you.

- Runs once at launch, then stops when you are in the world
- **Hold Escape** during the front-end to cancel and take over manually
- Skips destructive buttons (Delete, Quit, Create, Join server, etc.)
- May try the game's `LoadLatestSaveGame` path after the first menu advances

Requires [UE4SS for RSDragonwilds](https://www.nexusmods.com/runescapedragonwilds/mods/4).

Vanilla has no “continue last session” launch option; this is the QoL stand-in.
