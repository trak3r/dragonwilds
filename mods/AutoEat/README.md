# Teflon Ted's Auto Eat

> **One mod, one job** — no kitchen-sink configs or feature creep.

When **sustenance** or **hydration** drops below **50**, automatically eat or drink one matching item from inventory.

Player-facing Nexus copy, icon, and changelog live in [`nexus/`](nexus/). Pack with `..\..\Pack-Nexus.ps1 -Mod AutoEat`.

Requires [UE4SS for RSDragonwilds](https://www.nexusmods.com/runescapedragonwilds/mods/4).
