# Teflon Ted's Auto Potion

> **One mod, one job** — no kitchen-sink configs or feature creep.

When you are **poisoned**, automatically drink one **antipoison** potion from hotbar/backpack (weak → lesser → stronger).

Player-facing Nexus copy, icon, and changelog live in [`nexus/`](nexus/). Pack with `..\..\Pack-Nexus.ps1 -Mod AutoPotion`.

Requires [UE4SS for RSDragonwilds](https://www.nexusmods.com/runescapedragonwilds/mods/4).
